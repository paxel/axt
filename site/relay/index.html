For whoever runs a relay, the sealed mailbox that stores and forwards end-to-end encrypted messages and sees neither their content nor their type. Anyone can run one: AXT has no default relay operator, and each app chooses its relay.

The reference relay

The repository's reference relay is one Python program on the standard library. It is a reference and a test oracle, not a production server, and it runs behind a proxy that terminates TLS.

A relay of your own

A relay may be written in any language and store messages in any way, as long as it follows the interface and passes the conformance vectors.

  • Guide

    Write a relay of your own

    The mailboxes, the six requests and their codes, the holding time, limits, TLS and logs.

  • Guide

    Run the relay-server vectors

    Run them against the reference relay, and write the adapter for a relay of your own.

The interface every relay offers is in transports.md, section 5; the reference relay's own behaviour is in relay.md.
