The runner sends every vector of the categories an adapter names to that adapter and compares the answers. While a library is being written, it is run by hand, a category at a time.

What it needs

The runner is conformance/run.py. It needs Python 3.11 or later, fastavro to decode the messages an adapter writes, and the package cryptography to open what an adapter seals (conformance.md, section 7.1). It reads the vector files from the directory vectors/ at the top of the same tree.

A release archive holds the runner, the vectors and the uv.lock that pins what they need, as does a clone of the repository. With uv, uv sync in that directory installs it.

The command

The adapter's command comes after -- (conformance/README.md): 

python3 conformance/run.py -- <the adapter's command>

With the packages that uv installed:

uv run python conformance/run.py -- <the adapter's command>

Options

OptionEffect
--category NAMERuns only this category; it can be given more than once
--vectors DIRReads the vector files from another directory
--verboseNames every vector, not only those that fail

One category, with every vector named:

uv run python conformance/run.py --category time --verbose -- <adapter command>

There is no filter finer than a category. To work on one part, the adapter can name only the categories that are done so far, and --category narrows the run further.

What it reports

The runner first checks every vector file against the JSON Schema vectors.schema.json. It then starts the adapter and sends the vectors of the categories it names, file by file and in the order of each file (conformance.md, section 7.1), and checks every request and every answer against adapter.schema.json. It reports:

  • each vector that fails, by its id, with what differs;
  • for each category, how many of its vectors passed;
  • the categories the adapter does not name, as not run.

It exits with 0 only when every vector it ran passed. A vector fails when its answer differs from the expected result, and also when the adapter answers it as unsupported or with a failure of its own (section 6).

To see why a vector fails, look it up by its id in vectors/<category>/<category>.json. Its description says what it tests, its refs name the sections of the specification, and a note in its expected result may say why a negative vector fails (conformance.md, sections 3.1 and 4.1).

The reference adapter

The reference adapter passes every vector. Running it shows that the suite itself works on the machine at hand: 

uv run python conformance/run.py -- python conformance/reference/adapter.py

The scripts behind it, in conformance/tools/, also need avro and PyNaCl, and a time zone database that Python's zoneinfo finds; uv sync installs the packages (conformance/README.md).
