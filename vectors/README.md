# Test vectors

This directory holds the test vectors: bytes for every message and every example type, each with its expected meaning. Libraries use them to check that they encode and decode exactly as the specification says.

The vectors are added in [axt-1009](https://github.com/paxel/axt/issues/10); see [spec/conformance.md](../spec/conformance.md).
