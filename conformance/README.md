# Conformance suite

This directory holds the conformance suite that every AXT library must pass. It runs the [test vectors](../vectors/README.md) and the protocol steps against a library.

The suite is added in [axt-1009](https://github.com/paxel/axt/issues/10); see [spec/conformance.md](../spec/conformance.md).
