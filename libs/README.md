# Libraries

This directory holds the AXT libraries, one directory per language: `libs/<language>/`. A library implements the specification so that an app can offer, receive, sign and verify records without implementing AXT itself.

A library counts as conforming once it passes the [conformance suite](../conformance/README.md). How to propose a library is in [CONTRIBUTING.md](../CONTRIBUTING.md).
