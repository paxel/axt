# AXT specification

The specification of AXT, Avro eXchange Transfer, as separate documents. Each document is a stub until its ticket fills it.

| ----------------------------- | --------------------------------------------------------------------------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |

| [Types](types.md)             | The example types and the rules for evolving or replacing them              | written, 0.1.0 | [axt-1002](https://github.com/paxel/axt/issues/3)                                                                                                          |
| [Time](time.md)               | Dates, times of day, dates and times with their zone, and durations         | written, 0.1.0 | [axt-1016](https://github.com/paxel/axt/issues/17)                                                                                                         |
| [Metadata](metadata.md)       | Labels, emoji, formats, patterns and limits of a type's fields              | written, 0.1.0 | [axt-1017](https://github.com/paxel/axt/issues/18)                                                                                                         |
| [Fields](fields.md)           | Typed fields: the bricks a type is described with, and their checks         | written, 0.2.0 | [axt-1043](https://github.com/paxel/axt/issues/51)                                                                                                         |
| [Records](records.md)         | Record id and version, updates and deletions                                | written, 0.1.0 | [axt-1003](https://github.com/paxel/axt/issues/4)                                                                                                          |

| [Sync](sync.md)               | Stamps, merge and the messages between the devices of one owner             | written, 0.1.0 | [axt-1023](https://github.com/paxel/axt/issues/25), [axt-1024](https://github.com/paxel/axt/issues/26), [axt-1025](https://github.com/paxel/axt/issues/27) |
| [Shares](shares.md)           | Records shared with other users, their withdrawal, and proposals of changes | written, 0.1.0 | [axt-1026](https://github.com/paxel/axt/issues/28), [axt-1027](https://github.com/paxel/axt/issues/29)                                                     |
